# Руководство и База Знаний: Дисплей платы вейпа DM02i V03 (2428)

## 1. Общие сведения
Дисплей вейпа **DM02i V03** — это компактный монохромный/многоцветный сегментный LED-экран высокой плотности. Вся индикация (30 независимых светодиодных сегментов) управляется всего по **6 сигнальным линиям** с использованием технологии **Чарлиплексинга (Charlieplexing)**.

* **Разрешение матрицы**: 30 светодиодных элементов ($N \times (N-1) = 6 \times 5 = 30$).
* **Физический интерфейс**: 6-пиновый плоский шлейф/гребёнка.
* **Напряжение питания светодиодов**: 2.8 В – 3.3 В (прямое падение $V_F \approx 1.8\dots 2.8$ В).
* **Ток сегмента**: ~5–10 мА (ограничивается внутренним сопротивлением выходных каскадов GPIO чипа ~40–80 Ом).
* **Частота мультиплексирования**: оптимально 1.0 – 3.0 кГц (при 30 сегментах каждый сегмент обновляется с частотой 30–100 Гц, что полностью исключает видимое глазом или камерой мерцание).

## 2. Физическая распиновка (Контакты 1 .. 6)
Дорожки дисплея на плате DM02i подключены напрямую к ножкам микроконтроллера **Puya PY32C642 / PY32F002B** в корпусе **QFN-16**:

| Контакт дисплея | Физическая ножка МК (QFN-16) | Пин GPIO | Роль в Charlieplexing |
| :---: | :---: | :---: | :--- |
| **1** | **Ножка 14** | **`PB0`** | Линия 1 (Анод: Капля центр, сотня низ, D1_F, D2_D; Катод: D1_A..E) |
| **2** | **Ножка 13** | **`PB1`** | Линия 2 (Анод: Капля верх, молния, D1_A, D2_E; Катод: D1_F, D1_G, D2_A..C) |
| **3** | **Ножка 12** | **`PB2`** | Линия 3 (Анод: Капля лево, полоска 3, D1_B, D1_G; Катод: D2_D..G, %) |
| **4** | **Ножка 11** | **`PB3`** | Линия 4 (Анод: Капля низ, полоска 2, D1_C, D2_A, D2_F; Катод: Сотня верх, BOOST) |
| **5** | **Ножка 10** | **`PB5`** | Линия 5 (Анод: Капля право, D1_D, D2_B, D2_G; Катод: Полоски 1..3, молния, сотня низ) |
| **6** | **Ножка 9**  | **`PC1`** | **Линия 6 (ОБЩИЙ КАТОД ВСЕЙ КАПЛИ 💧; Анод: Полоска 1, %, Сотня верх, D1_E, D2_C)** |

## 3. Полная карта всех 30 сегментов матрицы

### 💧 Капля жидкости (5 сегментов)
Все 5 диодов капли сидят **катодом (-) на Контакте 6 (`PC1`)**:
* **`1(+) -> 6(-)`** (`PB0 -> PC1`): **Центральная капля**
* **`2(+) -> 6(-)`** (`PB1 -> PC1`): **Верх ободка капли**
* **`5(+) -> 6(-)`** (`PB5 -> PC1`): **Право ободка капли**
* **`4(+) -> 6(-)`** (`PB3 -> PC1`): **Низ ободка капли**
* **`3(+) -> 6(-)`** (`PB2 -> PC1`): **Лево ободка капли**

> [!TIP]
> Поскольку все 5 сегментов капли имеют общий катод на линии 6, их можно зажечь все разом без мультиплексирования: подав LOW (0V) на контакт 6, и HIGH (3.3V) на контакты 1, 2, 3, 4, 5.

### ━━━ Индикатор запаса жидкости (3 полоски)
* **`6(+) -> 5(-)`** (`PC1 -> PB5`): **Полоска 1** (Нижняя)
* **`4(+) -> 5(-)`** (`PB3 -> PB5`): **Полоска 2** (Средняя)
* **`3(+) -> 5(-)`** (`PB2 -> PB5`): **Полоска 3** (Верхняя)

### ⚡ Индикатор заряда и знаки
* **`2(+) -> 5(-)`** (`PB1 -> PB5`): **Молния ⚡** (Индикатор зарядки)
* **`6(+) -> 3(-)`** (`PC1 -> PB2`): **Знак процента `%`**
* **`6(+) -> 4(-)`** (`PC1 -> PB3`): **Сотня "1" — Верхняя палочка**
* **`1(+) -> 5(-)`** (`PB0 -> PB5`): **Сотня "1" — Нижняя палочка**

### 🚀 Индикатор BOOST (4 квадранта)
* **`1(+) -> 4(-)`** (`PB0 -> PB3`): **Верх-Лево** (Буква B)
* **`2(+) -> 4(-)`** (`PB1 -> PB3`): **Верх-Право** (Буква T)
* **`3(+) -> 4(-)`** (`PB2 -> PB3`): **Низ-Лево** (Диод 2)
* **`5(+) -> 4(-)`** (`PB5 -> PB3`): **Низ-Право** (Диод 4)

### 🔟 7-сегментный индикатор 1 (Десятки)
Расположение сегментов:
```text
      A
    F   B
      G
    E   C
      D
```
* Сегмент A: **`2(+) -> 1(-)`** (`PB1 -> PB0`)
* Сегмент B: **`3(+) -> 1(-)`** (`PB2 -> PB0`)
* Сегмент C: **`4(+) -> 1(-)`** (`PB3 -> PB0`)
* Сегмент D: **`5(+) -> 1(-)`** (`PB5 -> PB0`)
* Сегмент E: **`6(+) -> 1(-)`** (`PC1 -> PB0`)
* Сегмент F: **`1(+) -> 2(-)`** (`PB0 -> PB1`)
* Сегмент G: **`3(+) -> 2(-)`** (`PB2 -> PB1`)

### 🔢 7-сегментный индикатор 2 (Единицы)
* Сегмент A: **`4(+) -> 2(-)`** (`PB3 -> PB1`)
* Сегмент B: **`5(+) -> 2(-)`** (`PB5 -> PB1`)
* Сегмент C: **`6(+) -> 2(-)`** (`PC1 -> PB1`)
* Сегмент D: **`1(+) -> 3(-)`** (`PB0 -> PB2`)
* Сегмент E: **`2(+) -> 3(-)`** (`PB1 -> PB2`)
* Сегмент F: **`4(+) -> 3(-)`** (`PB3 -> PB2`)
* Сегмент G: **`5(+) -> 3(-)`** (`PB5 -> PB2`)

## 4. Алгоритм управления (Как подключить к любому МК)
Чтобы зажечь любой конкретный светодиод из 30:
1. **Все 6 линий перевести в режим High-Z (вход без подтяжки / Analog Input)**.
2. Линию **Анода (+)** перевести в режим **Output Push-Pull** и выставить уровень **HIGH (1, 3.3V)**.
3. Линию **Катода (-)** перевести в режим **Output Push-Pull** и выставить уровень **LOW (0, 0V)**.
4. Выдержать время слота (например, 300 микросекунд).
5. Снова вернуть обе линии в **High-Z** перед включением следующего диода (Dead-Time предотвращает двоение и паразитное свечение соседних сегментов).
