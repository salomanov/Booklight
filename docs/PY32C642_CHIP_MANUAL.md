# Справочное руководство: Puya PY32C642 / PY32F002BW15 (QFN-16)

> **Статус**: Проверено на реальном железе (DM02i V03 Vape Board)  
> **Архитектура**: 32-битное ядро ARM Cortex-M0+, тактовая частота до 24 МГц  
> **Корпус**: QFN-16 (3x3 мм, шаг 0.5 мм, термопад GND снизу)

---

## 1. Общие характеристики микроконтроллера

| Параметр | Значение |
|---|---|
| **Ядро** | ARM Cortex-M0+ (32 бит, гарвардская архитектура, 2-ступенчатый конвейер) |
| **Максимальная частота** | 24 МГц (встроенный высокоточный генератор HSI) |
| **Flash-память** | 24 КБ (сектора по 128 байт, страницы по 32 байта) |
| **SRAM** | 3 КБ (адрес `0x20000000` .. `0x20000BFF`) |
| **Диапазон питания VDD** | 1.7 В – 5.5 В (идеально для прямого питания от Li-Ion 3.0–4.2 В) |
| **АЦП (ADC)** | 12-битный SAR ADC, до 1 MSPS, каналы 0..9 + VREFINT (1.20 В) |
| **Таймеры** | TIM1 (16-бит advanced с комплементарными ШИМ-выходами), TIM14 (16-бит общего назначения) |
| **Интерфейсы связи** | 1x USART, 1x I2C, 1x SPI |
| **Режимы энергопотребления** | Sleep, Stop (< 5 мкА с сохранением SRAM), Standby |
| **Отладка** | 2-проводной интерфейс SWD (SWCLK: PA2, SWDIO: PB6) |

## 3. Критически важные особенности архитектуры и аппаратные "грабли"

### 3.1. Защита от "окирпичивания" SWD (DBGMCU)
При переходе микроконтроллера в режим сна (STOP / STANDBY) или при ошибочной переконфигурации выводов SWD (`PA2` и `PB6`), программатор (ST-Link / J-Link) мгновенно теряет связь с чипом, выдавая ошибку `Cannot connect to target`.

**Решение (обязательно внедрять в `dm02i_board_init()`):**
```c
// 1. Включаем тактирование контроллера отладки
RCC->APBENR1 |= RCC_APBENR1_DBGEN;

// 2. Разрешаем SWD-отладку даже в режиме Stop
DBGMCU->CR |= DBGMCU_CR_DBG_STOP;

// 3. Замораживаем таймеры (TIM1, TIM14, WDT) во время паузы отладчика
DBGMCU->APBFZ1 |= 0xFFFFFFFF;
```

> **Важно**: При работе с портом `GPIOB` (Charlieplexing) никогда не применяйте групповую маску `0xFFFF` к регистрам `GPIOB->MODER`. Всегда маскируйте выводы дисплея строго побитово (`PB0, PB1, PB2, PB3, PB5`), оставляя `PB6` (SWDIO) нетронутым!

---

### 3.2. Тактирование Порта C (`PC1` - 6-я линия дисплея)
В семействах PY32F002B / PY32C642 порт C по умолчанию отключен для экономии энергии. Ножка 9 чипа физически принадлежит порту `GPIOC` (`PC1`). Если не включить тактирование `RCC_IOPENR_GPIOCEN`, любые записи в `GPIOC->MODER` и `GPIOC->ODR` игнорируются, из-за чего Капля и нижние сегменты дисплея не горят.

```c
// Обязательное включение тактирования GPIOC:
RCC->IOPENR |= RCC_IOPENR_GPIOCEN;
__HAL_RCC_GPIOC_CLK_ENABLE();
```

---

### 3.3. Измерение напряжения аккумулятора без внешнего делителя (VREFINT)
Микроконтроллер PY32C642 питается напрямую от аккумулятора Li-Ion ($V_{DD} = V_{BAT} = 3.0 \dots 4.2\text{ В}$). Напряжение $V_{DD}$ является опорным напряжением для АЦП.
Внутри чипа есть встроенный калиброванный источник опорного напряжения $V_{REFINT} = 1.20\text{ В}$ (подключен к специальному внутреннему каналу АЦП `ADC_CHANNEL_VREFINT`).

Формула вычисления текущего напряжения батареи $V_{BAT}$ в милливольтах:
$$V_{BAT}\text{ (мВ)} = \frac{1200 \times 4095}{\text{RAW}}$$

Где:
- $1200$ — опорное напряжение $V_{REFINT}$ в мВ (1.20 В).
- $4095$ — максимальное значение 12-битного АЦП ($2^{12} - 1$).
- $\text{RAW}$ — измеренное значение АЦП по каналу `ADC_CHANNEL_VREFINT`.

**Преимущества:**
- Не требуется внешних резистивных делителей на плате.
- Ноль тока утечки через резисторы делителя во время сна.
- Точность измерения: $\pm 15\text{ мВ}$.

## 5. Прошивка и отладка через SWD (J-Link / ST-Link)

### 5.1. Подключение к отладочным пятакам DM02i
Плата DM02i V03 снабжена удобными круглыми пятаками с шагом 1.27/2.0 мм:
1. **`V`** $\to$ Питание $V_{DD}$ ($3.3\text{ В}$ от программатора или от АКБ)
2. **`R`** $\to$ `NRST` (Пин сброса чипа, ножка 2 `PC0`)
3. **`D`** $\to$ `SWDIO` (Линия данных, ножка 16 `PB6`)
4. **`C`** $\to$ `SWCLK` (Линия тактирования, ножка 5 `PA2`)
5. **`G`** $\to$ `GND` (Общая земля)

### 5.2. Параметры J-Link в OpenOCD / PyLink
- **Device**: `Cortex-M0+` (или `PY32F002Bx5`)
- **Интерфейс**: `SWD`
- **Частота SWD**: `1000 кГц` – `2000 кГц` (надежно работает на проводах до 30 см)
- **Init sequence**: сброс подтяжкой `NRST` к GND перед подключением (`ConnectUnderReset`) при наличии зависших прошивок.
